# 실험 기록

노트북 번호 순서대로 목적, 핵심 결과, 판정을 적는다. 수치는 Stellantis N.V.의 숨긴 타점 라벨로 채점한 값이며, 별도 표시가 없으면 일자 단위 교차검증(불량 79건)이다.
시도한 모델 사양은 모두 기록했고, 결과를 본 뒤 고른 조합은 '탐색'으로 표시했다.

## 1차 실험 (`exp/`)

| 번호 | 목적 | 결과 | 판정 |
|---|---|---|---|
| 01 | 데이터·묶음 조건·평가 지표 점검 | 위치 번호만으로 AUROC 0.79 (위치 쏠림 확인) | 같은 위치 안 지표 추가 |
| 02 | 후보 모델 × 묶음 조건 4종 × 5시드 (통과 기준 사전 고정) | 비율·개수 손실, 물리규칙, 의사라벨 모두 같은 위치 안 AUROC 0.5 근처 | 통과 0개 |
| 03 | 입력 변형 (가압력 제외, 위치 평균 제거) | 입력 3종 × 모델 5종 모두 기준 미통과 | - |
| 04 | KAMP 일자 단위 개수 예측 (8일) | 물리규칙 사전지식 MAE 1.70, 고정 불량률 2.19 (p≈0.14) | 개선 미확인 |
| 05 | 순서 피처 (직전 20타점 편차, 직전 변화량) | 무작위와 구분 안 됨 | - |
| 06 | KAMP 2단계 파이프라인 첫 구성 | `results/kamp_priority.csv` | 이후 2차 실험으로 대체 |
| 07 | 복사 블록 경계 효과, AE 입력 비교 | 상위 타점 구간 쏠림은 전처리 착시 아님 | - |
| 08 | 불량 유형별 물리 방향 규칙 (학습 없음) | 같은 위치 안 AUROC 0.47~0.54, 구간이 0.5 포함 | 신호 인정 안 함 |
| 09 | 유형별 부호 고정 개수 모델 (KAMP 8일) | 합계 MAE 1.90 (고정 불량률 2.19, 부호 자유 1.78) | 미채택 |
| 10 | 양성 대조 (파형 모양 피처) | 파형 피처에는 위치 안 신호가 남음 | 평가 코드 정상 확인 |
| 11 | 새 시드(5~14)로 의사라벨 모델 확인 | 4조건 평균 같은 위치 안 AUROC 0.601 (비율 손실 0.612보다 낮음) | 사전 규칙상 고정 안 함 |
